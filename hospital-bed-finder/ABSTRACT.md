# Abstract

**Hospital Bed Finder** is a web-based application that helps users locate nearby hospitals and view real-time availability of general and ICU beds during emergencies. The system uses the browser’s geolocation API to get the user’s position, fetches hospital data from OpenStreetMap (OSM) via the Overpass API within a configurable radius (10, 25, or 50 km), and stores hospital records in a local SQLite database. Hospitals are displayed as cards with bed counts and distance, and an interactive Leaflet map shows their locations after the user allows location access. An admin panel (protected by login) allows authorized users to update general and ICU bed counts for each hospital and to search hospitals by name. The application is built with Flask (Python) on the backend and HTML/CSS/JavaScript with Leaflet on the frontend. It is intended as a demonstration project for emergency bed discovery and is not intended for production or real emergency use without further hardening and integration with official health systems.
